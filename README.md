# Albéa & Co — Studio créatif

Application (un seul fichier `index.html`) pour créer, à partir des photos de votre lampe en albâtre :
- 🎬 **TikTok** : vidéos verticales 9:16 (Kling via fal.ai), avec mise en scène IA optionnelle ;
- 📸 **Photo produit** : packshots fond blanc et photos lifestyle jusqu'en 4K (Nano Banana Pro via fal.ai) ;
- 🌐 **Site web** : bannières et visuels (16:9, 21:9, 3:2…) en PNG / JPG / WEBP.

## Mettre la clé API
1. Créez un compte sur https://fal.ai puis une clé sur https://fal.ai/dashboard/keys.
2. Au choix :
   - collez-la dans l'app (bloc « Connexion IA ») — elle reste dans votre navigateur ;
   - ou ouvrez `index.html` dans un éditeur de texte et remplissez `var FAL_API_KEY = "";` tout en haut.

⚠️ Ne publiez jamais (GitHub, site public…) un fichier qui contient votre clé.

## Utiliser
Double-cliquez sur `index.html` (ou ouvrez-le dans Safari/Chrome sur téléphone). Ajoutez vos photos, choisissez l'ambiance, lancez.
